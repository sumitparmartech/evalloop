03 / What it catches

Eight ways agents fail in production

Each one is a check you attach to a case. They run on the full trace, so you assert on what the agent did, not only on what it said.

Flaky runs

Every case runs k times. A case is reliable only if all k pass. pass^k

Hallucinated numbers

Flags any number the agent states that is not in the input or a tool result. grounded()

Prompt injection

Fails the run if a secret planted in a tool result reaches the user. no_secret_leak()

Wrong tools or order

Assert which tools ran, with which arguments, in which order. tool_order()

Loops

Catches the same tool call repeated with the same arguments. no_loop()

Cost creep

Set a budget per run in dollars and fail the build when a prompt change blows it. cost_under()

Slow answers

Latency is measured per step and per run, with p50 and p95 in every report. latency_under()

Your own rule

Any function of the trace is a check. Return a bool or a bool with a reason. custom()

04 / How it works

Record the trace, check it, gate the merge

Wrap your agent with a tracer once. Everything after that is data you can diff.

agent_evals.py
from evalloop import Case, run_suite, tool_order, tool_args, grounded

cases = [
  Case("refund_small_order", "Please refund order #1042", [
    tool_order("lookup_order", "issue_refund"),
    tool_args("issue_refund", order_id="1042", amount=49.0),
    grounded(),
  ])
]

result = run_suite(my_agent, cases, trials=5)
# result.pass_rate, result.reliability, result.save("run.json")

05 / CI gate

A prompt tweak that breaks a case never reaches main

Save a baseline run. On every pull request, evalloop compares against it and exits with code 1 when any case gets worse or the pass rate drops under your threshold.

.github/workflows/agent-evals.yml
# .github/workflows/agent-evals.yml
- name: Run evals and gate on regressions
  run: |
    python -m evalloop.cli run suite:cases \
      --agent support_agent:agent_v2 \
      --trials 5 --seed 2 \
      --baseline docs/run_v2.json \
      --fail-on-regression --fail-under 0.95 \
      --html report.html
- uses: actions/upload-artifact@v4
  if: always()
  with: { name: evalloop-report, path: report.html }
